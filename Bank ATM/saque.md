## Iniciando projeto vite

npm create vite@latest saque-bancario
criar arquivo vite.config.js
@import "tailwindcss" no css;
npm run dev
npm install tailwindcss@latest

## Lógica do exercício

1. Saldo inicial = 1000
2. Usuário informa valor
3. Verificar se valor é válido
4. Verificar se há saldo
5. Verificar se o caixa consegue formar o valor
6. Subtrair do saldo
7. Mostrar notas entregues
8. Mostrar novo saldo
